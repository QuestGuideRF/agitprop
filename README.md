# Agitprop

Генератор текстов в стиле советской пропаганды на основе нейронных сетей (Transformer).

## ✨ Особенности

- Генерация текста на основе Transformer-архитектуры (PyTorch)
- Обучение модели на произвольных текстовых корпусах
- BPE-токенизация с использованием YouTokenToMe
- Beam Search для генерации качественных продолжений текста
- Интерактивный режим генерации

## 🚀 Быстрый старт

### Установка зависимостей

```bash
pip install torch numpy matplotlib youtokentome
```

### Тренировка модели

```bash
python train.py <текст> <имя_модели> <batch_size> <epochs>
```

**Пример:**
```bash
python train.py text.txt propaganda_model 128 1000
```

**Параметры:**
- `текст` — имя файла с текстом для обучения (должен находиться в папке `texts/`)
- `имя_модели` — имя выходной модели (сохраняется в папку `models/`)
- `batch_size` — размер батча (рекомендуется 128)
- `epochs` — количество эпох обучения

### Генерация текста

```bash
python beam_gen.py <модель.pth> <модель.yttm>
```

**Пример:**
```bash
python beam_gen.py propaganda_model.pth propaganda_model.yttm
```

После запуска введите начальные слова, и модель сгенерирует продолжение текста. Для выхода введите `quit`.

## 📁 Структура проекта

```
agitprop/
├── train.py              # Скрипт обучения модели
├── beam_gen.py           # Скрипт генерации текста
├── libs/                 # Библиотеки для работы с данными и обучения
│   ├── base.py           # Базовые утилиты
│   ├── pipeline.py       # Pipeline обучения
│   ├── visualization.py  # Визуализация
│   └── data/             # Модули обработки данных
├── texts/                # Папка для текстовых корпусов
└── models/               # Папка для сохранения моделей
```

## 🛠 Использование

1. Поместите текстовый корпус в папку `texts/`
2. Запустите обучение модели
3. После обучения используйте `beam_gen.py` для интерактивной генерации

**Пример сессии генерации:**
```
Insert text or 'quit' to exit
Text:
> Партия
****
-2.45
Партия ведет народ к победе коммунизма...
```
